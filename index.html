Drive figures are typical small-block random IOPS and vary widely by model; use your drive's datasheet or a measured fio result for real sizing. The array model ignores controller cache, SSD write amplification and full-stripe writes, so treat it as a planning estimate. Usable capacity is before filesystem overhead and vendor reserve; drives are sold in decimal TB, while operating systems usually show binary TiB. The bottleneck model uses rough CPU cost per I/O and assumes reads are spread evenly over the hot working set, so the cache hit ratio is RAM cache ÷ working set (capped at 95%). Benchmark your own stack before you buy hardware.
